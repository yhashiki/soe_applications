# Контроль заявок

Веб-приложение для контроля заявок. Стек: **React + TypeScript + Vite + Tailwind CSS**.

## Возможности

- Создание заявки: филиал (РДУ / ОДУ / ЦДУ), номер заявки, комментарий с описанием работ.
- Статусы заявки: «Не начато», «Ведутся работы», «Приостановлены».
- Удаление заявки.
- Счётчики по статусам (всего / ведутся / приостановлены / не начато).
- Экспорт оставшихся (активных) заявок в CSV — открывается в Excel.
- Данные сохраняются в браузере (`localStorage`) и не теряются между перезагрузками.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
```

## Структура

```
src/
  App.tsx                  — главный экран, состояние и логика
  types.ts                 — типы (Заявка, статусы, филиалы)
  storage.ts               — хук с сохранением в localStorage + демо-данные
  export.ts                — экспорт активных заявок в CSV
  components/
    NewZayavkaForm.tsx     — форма создания заявки
    ZayavkaRow.tsx         — строка заявки в списке
    StatusBadge.tsx        — бейдж статуса
    Icons.tsx              — inline-SVG иконки
```

При первом запуске показываются демонстрационные заявки. Их можно удалить — список начнёт сохранять только ваши данные.
